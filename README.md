# ROTO-CONTROL Mapping Library

Ready-made plugin mappings for the Melbourne Instruments ROTO-CONTROL, for Ableton Live, Logic Pro and Bitwig Studio.

This is an independent library. It isn't made or checked by Melbourne Instruments.

## What's here

- `mappings/ableton/`, `mappings/logic/`, `mappings/bitwig/`: one file per plugin, named after the plugin and its format, for example `Decapitator (AU).json` or `ChromaVerb (Logic stock).json`.
- `index.json`: the list of every mapping, with its plugin, developer, type and label.

Each mapping has a label:

- **Approved**: checked on a ROTO-CONTROL in its DAW before it was published.
- **Community**: shared by a user. Not checked by us. Other users can say whether it works for them.

## Using a mapping

The easiest way is the ROTO-CONTROL Library app: open **Pick your plugins** and tick the plugins you want. The app adds them to your library, and never replaces a mapping you already have unless you ask it to.

Without the app, download a file and import it with Melbourne Instruments' Roto-Setup.

## Sharing your own

Users of the app can share a mapping with **Share to the online library…**. Shared mappings are looked at before they're published, under the terms in [TERMS.md](TERMS.md).
